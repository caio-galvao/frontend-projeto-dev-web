# frontend-projeto-dev-web

Este é o frontend do projeto **Dev Web**, desenvolvido com React e Chakra UI. O projeto é responsável por gerenciar a interface do usuário, incluindo autenticação, edição de perfil, exibição de posts e gerenciamento de prédios.

---

## **Pré-requisitos**

Antes de começar, certifique-se de ter as seguintes ferramentas instaladas em sua máquina:

- [Node.js](https://nodejs.org/) (versão 16 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

---

## **Instalação**

1. Clone o repositório:

   ```bash
   git clone https://github.com/seu-usuario/frontend-projeto-dev-web.git

2. Acesse o diretório do projeto:

   ```bash
   cd frontend-projeto-dev-web/sentaai
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

---

## **Execução**

1. Execute o projeto em modo de desenvolvimento:

   ```
   npm run dev
   ```

2. Acesso o endereço:

   ```
   http://localhost:8080
   ```
